# FFmpegKit Extended native bridge

`ffmpeg_kit.dart` adapts the FFmpegKit Extended Flutter 0.6.2 generated FFI
bindings and session execution API by Akash Patel for standalone Dart use.
Copyright (C) 2026 Akash Patel. Licensed under LGPL-2.1-or-later.
Upstream: https://github.com/akashskypatel/ffmpeg-kit-extended

The pinned FFmpegKit Extended 0.11.1 small LGPL bundles contain FFmpeg 9.0.1.
The accompanying `FFmpeg-LICENSE.txt` is the exact LGPL v3 text shipped in
the pinned upstream Linux and Windows release archives and source commit
`4dc903c2a29741b8f9b61dd94b10185bae69a493`. FFmpeg's LGPL v2.1 source
license is at https://ffmpeg.org/legal.html.
Source and release notices: https://github.com/akashskypatel/ffmpeg-kit-builders
The build hook downloads SHA-256-verified release archives; native source builds
are never part of normal development or client builds.
