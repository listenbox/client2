The Dart FJS bindings in `lib/src/frb` are copied from FJS 3.3.0
(https://github.com/fluttercandies/fjs), generated by flutter_rust_bridge
2.12.0. Three obsolete `final` parameter modifiers in Freezed output were
removed for Dart 3.13 syntax; the native binding protocol is unchanged.
See FJS-LICENSE.txt. The matching native libfjs
binary must be built from that same FJS source and generated binding ABI.

The YouTube.js source and license are in the pinned client workspace Git
submodule `vendor/youtubejs`. The ESM bundle is generated from that source.
